# Auto Glass Search OS Visual System

## Direction

Premium automotive precision meets enterprise search technology. The system should feel engineered, credible, operational, and specific to established auto glass operators—never like generic SaaS, an ad agency template, or speculative AI software.

## Identity

- Use the geometric **AG** monogram as the compact brand mark.
- Pair it with the Auto Glass Search OS wordmark in Inter.
- Keep the mark precise, flat, and legible at navigation and favicon sizes.
- Do not add decorative gradients, chrome effects, glow, or automotive clichés.

## Color

- Deep navy is the authority color and primary dark surface.
- Electric blue is reserved for interactions, active states, links, technical indicators, and concise emphasis.
- Off-white is the primary light surface.
- Graphite, slate, and quiet blue support hierarchy without competing with the brand colors.
- Semantic colors must be used only for the meaning they communicate.

## Typography

- Inter is the sole primary family for headings, body copy, navigation, buttons, and forms.
- IBM Plex Mono is a sparse technical accent for eyebrows, stage numbers, annotations, and system metadata.
- Use sentence case for body content. Keep uppercase tracked text to short labels.
- Headlines should wrap deliberately and remain readable at mobile widths.

## Layout and spacing

- Build spacing on an 8px base.
- Use a maximum 1280px site container and a 720px prose measure.
- Prefer clear sections, thin dividers, aligned grids, and generous whitespace.
- Keep radii restrained. Components should feel machined rather than soft or playful.

## Components

- Buttons share a common height, typography, focus treatment, and disabled behavior.
- Cards use flat surfaces and thin borders rather than heavy shadows.
- Forms always use visible labels; placeholders are examples, not substitutes for labels.
- Navigation uses a clear active state and a visible keyboard focus state.
- Tables use semantic headers and remain horizontally usable on narrow screens.

## Accessibility and motion

- Maintain WCAG AA contrast for normal text and controls.
- Preserve one H1 per page and a logical heading hierarchy.
- Every interactive element needs a visible `:focus-visible` treatment.
- Respect `prefers-reduced-motion`; motion should communicate state, not decorate the page.
